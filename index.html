apt repository

Packages from Sand Software Solutions for Debian, Ubuntu and derivatives (amd64 and arm64):

  • foundry: create new projects from your own templates. GitHub
  • assay: see whether files were changed. GitHub

Install

One line (read setup.sh first if you like; it only adds the key and the source, and installs nothing):

curl -fsSL https://sandsoftwaresolutions.github.io/apt/setup.sh | sudo sh
sudo apt install foundry assay

Or by hand:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://sandsoftwaresolutions.github.io/apt/key.asc | sudo tee /etc/apt/keyrings/sandsoftwaresolutions.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/sandsoftwaresolutions.asc] https://sandsoftwaresolutions.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/sandsoftwaresolutions.list
sudo apt update
sudo apt install foundry assay

Updates arrive with your normal sudo apt upgrade.

Remove

curl -fsSL https://sandsoftwaresolutions.github.io/apt/setup.sh | sudo sh -s -- --remove
# or by hand:
sudo apt remove foundry assay
sudo rm /etc/apt/sources.list.d/sandsoftwaresolutions.list /etc/apt/keyrings/sandsoftwaresolutions.asc

About the signature

The repository is signed with a dedicated key; the public key is key.asc. The signed-by option above limits that key to this repository only. Packages are built by GitHub Actions from tagged releases; each release also carries a SHA256SUMS file.
